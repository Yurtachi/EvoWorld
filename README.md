# EvoWorld

Sandbox 2D de vida artificial (Godot 4.7.2, GDScript). Veja `docs/mission/` para visão e metas.

## Rodar
    godot --path .                                        # jogo
    godot --headless --path . -s tests/run_tests.gd       # testes (exit 0 = ok)

Godot 4.7.2: `winget install -e --id GodotEngine.GodotEngine`.
